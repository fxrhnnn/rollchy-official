## 📌 Project Overview
**Rollchy** is a Malaysian student-inspired snack brand concept featuring handcrafted crispy snacks. The name is a fusion of **"Roll"** (inspired by the signature Ramen Roll) and **"chy"** (from the irresistible crunchiness).

This website serves as an academic e-commerce showcase demonstrating:
- Digital brand positioning and value propositions
- Product catalogue and WhatsApp-integrated direct ordering simulation
- Responsive web design across Desktop, iPad, and Mobile viewports
- Customer service FAQs and academic project declarations

## 🛠️ Technology Stack
- **HTML5 & Vanilla CSS3**: Semantic layout, responsive grid, custom typography, and CSS micro-animations.
- **Bootstrap 4**: Grid structure and responsive container utilities.
- **JavaScript & jQuery**: Slick slider carousel for customer reviews and dynamic mobile drawer navigation.
- **Hosting**: Netlify static deployment with global CDN and SSL encryption.
